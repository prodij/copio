## Brand Promise

> A colleague who already read everything overnight. Apple quality. Honest voice. Self-improving. Not a dashboard, a colleague.

Every design decision either earns this promise or erodes it. When in doubt, ask: would Apple ship this? Would a thoughtful human chief of staff put this on the page?

## Aesthetic Direction (rev 2)

**Reference points:**
- apple.com/iphone-15-pro, apple.com/vision-pro, apple.com/mac
- macOS Sequoia + Sonoma desktop aesthetic (Mail, Notes, Messages, Notion Calendar, Things 3)
- Linear's product pages and pricing
- Apple Keynote slide aesthetic (clean type, generous whitespace, premium photography)

**Anti-references (NOT what we are):**
- Claude.ai (warm + serif + dark)
- ChatGPT / OpenAI's site (generic AI assistant)
- Cookie-cutter SaaS (3-col feature grids, gradients, icons-in-circles)
- Generic "AI startup" templates

The aesthetic is **calm, premium, intentional, light-mode-primary, cool-toned, sans-throughout, bento-organized for landing, macOS-native-feeling for chat.**

## Color System

Use CSS custom properties throughout — no hardcoded hex values in component code. Define once in `globals.css`, reference everywhere.

### Anti-patterns (forbidden — instant fail)

- **No purple/violet/indigo** anywhere. The 2024-2025 SaaS purple gradient is the most recognizable AI-slop signal.
- **No warm ochre / orange / amber** as the brand accent. (Rev 1 used ochre — rev 2 explicitly replaced.)
- **No gradient backgrounds** except very subtle ones (1-2% lightness shift between bento cells).
- **No multi-accent system.** Exactly ONE accent (Apple blue). Apple-system colors (green/orange/red) are reserved for status states only.
- **Dark mode is a toggle, not the default.** Pages must look right in light mode first.

## Typography

**Family rule:** Inter Display + Inter. One family, optical-size adjusted. Adding any other typeface (including a serif accent) is a smell.

### Display — Inter Display

- **Use:** landing page hero headline, bento cell headlines, brand wordmark
- **Weights:** 500 medium, 600 semibold, 700 bold (sparingly)
- **Optical size:** Inter Display is optical-size adjusted for ≥24px

### Body / UI — Inter

- **Use:** chat message body, sidebar threads, UI labels, button text, citation pills, all microcopy
- **Weights:** 400 regular, 500 medium, 600 semibold (sparingly)
- **Avoid:** system-ui, -apple-system as primary fallback. Inter is shipped via WOFF2 self-hosted; system-ui only as emergency fallback.

### Type scale (8pt base)

| Role | Size | Line height | Weight | Family |
|---|---|---|---|---|
| Display XL (landing hero) | clamp(40px, 6vw, 72px) | 1.05 | 600 | Inter Display |
| Display L (bento cell headlines, "WHO COPIO IS FOR") | 32px | 1.15 | 600 | Inter Display |
| Display M (sample brief cell question header) | 13px / small caps tracked +0.06em | 1.4 | 600 | Inter |
| Heading 1 (chat thread page title) | 18px | 1.3 | 600 | Inter |
| Heading 2 (sidebar section subhead, e.g. "Capabilities") | 11px / small caps tracked +0.04em | 1.4 | 600 | Inter |
| Body (chat messages, landing prose, sample brief prose) | 16px | 1.55 | 400 | Inter |
| Body small (sidebar previews, captions) | 14px | 1.5 | 400 | Inter |
| Caption (timestamps, citation pill text, footer) | 12px | 1.4 | 500 | Inter |

### Voice rendering rules — the honest-voice visual spec

The single most load-bearing typographic rule. The brand promise dies if uncertainty markers render the same as cited facts.

- **"I can see X" facts (cited):** Inter regular 400, `--text-primary`. Citation superscript follows the claim immediately.
- **"I infer Y" claims:** Inter italic 400 (NOT serif italic — same family, italic style), `--text-muted` color. Lighter weight via color, not font-weight.
- **Uncertainty markers** (e.g. "I'm 70% on this"): Inter italic 400, `--text-muted`, parenthetical. Wrapped in soft brackets if not natural to the sentence.
- **Persona's name** in landing prose / chat: Inter medium 500, `--text-primary`. Capitalized normally (not small-caps unless it's the chat persona-attribution row).

Rev 1 used Tiempos italic + warm ochre for these — replaced with **Inter italic + cool muted gray**. The visual differentiation between cited and inferred is now via color shift + italic style, NOT font family.

```
Sales fell 8% MoM¹ — primarily driven by ad CPC increases². I infer this is competitor pressure rather than seasonality, but I'm 70% on this.
```

In rendered HTML:
```html
Sales fell 8% MoM<sup class="cite">¹</sup>, primarily driven by ad CPC increases<sup class="cite">²</sup>.
<em class="inferred">I infer this is competitor pressure rather than seasonality,
but I'm 70% on this.</em>
```

CSS:
```css
.inferred { font-style: italic; color: var(--text-muted); font-weight: 400; }
sup.cite  { color: var(--accent-text); font-size: 0.7em; vertical-align: super; cursor: pointer; }
sup.cite ~ * { /* dotted underline on the preceding word group via JS or special markup */ }
```

### Em dashes — forbidden

Per Garry's law. Use periods, commas, parentheses, or hard line breaks. Never `—` or `–`.

## Spacing

8pt base. Every spacing value is a multiple of 8 (or 4 for tight contexts).

```css
--space-1:  4px;
--space-2:  8px;
--space-3:  12px;
--space-4:  16px;  /* base spacing unit */
--space-6:  24px;
--space-8:  32px;
--space-12: 48px;
--space-16: 64px;
--space-24: 96px;  /* hero vertical breathing room */
--space-32: 128px; /* between landing sections, generous */
```

### Layout spacing rules

- **Chat sidebar width:** 240px desktop, drawer 280px mobile.
- **Chat main column max-width:** 720px (centered) — keeps line length readable.
- **Landing bento max-width:** 1200px (centered, generous margins on viewport >1280px).
- **Landing bento cell gap:** `--space-6` (24px) on desktop, `--space-4` (16px) on tablet, `--space-3` (12px) on mobile.
- **Bento cell corner radius:** 16px (small/medium cells), 20px (hero cell). NEVER 32px+ (bubbly), NEVER 0px (sharp/aggressive).
- **Section vertical breathing room (landing):** `--space-24` minimum between bento and footer; `--space-12` between top nav and bento.
- **Message vertical spacing in chat:** `--space-8` (32px) between messages, `--space-3` (12px) within message blocks.

## Bento Spec (landing page)

The landing page is a heterogeneous bento grid, not a vertical scroll of sections. Each cell is its own moment. Asymmetric sizes — sample brief cells are larger than differentiator cells, hero is full-width.

### Bento system

- **Grid:** CSS grid with `grid-template-columns: repeat(12, 1fr)`. Cells span 4-12 cols, 1-2 rows.
- **Corner radius:** 16px (default), 20px (hero cell).
- **Background:** `--bg-bento-cell` (white) for most; `--bg-bento-tint` (subtle cool gray) for visual rhythm on every other cell or specific cells (e.g. founder cell, pricing cell).
- **Padding:** `--space-8` (32px) for medium cells; `--space-12` (48px) for hero cell.
- **Shadow:** none. Bento cells are flat; the cool-gray page bg + white cells provides the depth signal.
- **Border:** none in light mode. In dark mode, a 1px `--border-subtle` rim per cell.

### Cells (approved Variant A — locked)

The mockup is the source of truth on layout. Order top-to-bottom:

1. **Top nav (above bento):** thin 56px bar, `copio` wordmark left in Inter Display 18px medium, "Pricing" + "Sign in" links right in Inter 14px regular `--text-secondary`. Wordmark is plain text styled, no logo glyph.
2. **Hero cell (full-width, 12 cols, 1 row):** display headline "The brief your CEO has been waiting for" in Inter Display clamp(40px, 6vw, 72px) weight 600 `--text-primary`. Below: 1-line subhead in Inter 18px regular `--text-secondary`. Below subhead: Apple-blue CTA "Get a brief" — Inter 16px semibold, white text on `--accent` background, 12px corner radius, padding `--space-3` × `--space-6`.
3. **Three sample brief cells (4 cols each, 1 row):** each cell shows:
   - Question header in Inter 13px semibold small-caps tracked +0.06em `--text-muted` (e.g. "OPPORTUNITY DIAGNOSTIC").
   - Question itself, 1 line, Inter 18px medium `--text-primary` (e.g. *"What gives Copio a better ability to rank for competitive keywords?"*).
   - 2-3 sentences of agent prose, Inter 15px regular 1.55 line-height `--text-primary`. Includes ONE citation pill (superscript ¹) and ONE inline italic uncertainty marker line ("I'm 70% on this") in `--text-muted`.
   - Pill row at bottom showing source ("SP-API") in `--accent-text` 12px semibold, with optional confidence label "UNSURE" or "70%" in cool muted gray.
4. **"WHO COPIO IS FOR" cell (4 cols, 1 row):** "WHO COPIO IS FOR" header in small-caps, then plain prose: "$1M-$50M Amazon-native CEOs." Inter 18px regular `--text-primary`. No icons.
5. **Three differentiator cells (4 cols each, 1 row, NOT a 3-col symmetric grid):** each cell ≠ icon + bullet. Cells SIZED DIFFERENTLY in the bento for visual rhythm. Each cell: a single-line voice-driven differentiator headline in Inter Display 24px medium `--text-primary`. NO supporting copy. NO icons.
   - "Honest, not helpful."
   - "Reads everything overnight."
   - "Self-improving eval rig."
6. **Founder cell (4 cols, 1 row, `--bg-bento-tint`):** plain prose "Built by James Han, 7-figure Amazon Nutra seller." Inter 18px regular `--text-primary`. No headshot circle decoration.
7. **Pricing cell (4 cols, 1 row, `--bg-bento-tint`):** "$199-499/mo." in Inter Display 24px semibold, then "Founding members locked in." in Inter 16px regular `--text-secondary`. Single price line — NOT a 3-tier table.
8. **Footer:** thin row at very bottom, Inter 12px regular `--text-muted`. Content: `© 2026 Copio · Privacy · Terms · Manifesto · hello@copio.app`.

### Sample cell content rule (Pass 4 lock-in)

**Sample brief cells must use real Nutragroup ASINs and real numbers.** Generic placeholders ("SKU-A", "Product X", "$XYZ") are forbidden — they read engineering-demo, not embodied. Real category (supplements / personal care), real-shape ASINs (e.g. B0CX1234YZ), real ad spend / conversion / inventory numbers from the founder's Amazon business. The marketing site is the founder's domain expertise made tangible.

### Voice-driven copy rule (Pass 4 lock-in)

Any bento cell that reads like template copy ("Powerful AI insights", "Built for scale", "Trusted by leaders", "Unlock the power of") fails the brand promise. The bento isn't a list of features — it's the agent's voice on the page. If a cell could appear on a competitor's site without changing a word, rewrite it.

### Bento responsive collapse

- **Tablet (768-1199px):** 2-column grid. Hero spans both columns. Sample cells go 2-up. Differentiators stack 1-up below sample cells. Founder + pricing 2-up.
- **Mobile (≤767px):** Single column stack. Every cell becomes full-width. Cell padding reduces to `--space-6` (24px). Order: hero → sample 1 → sample 2 → sample 3 → "Who Copio is for" → differentiator 1 → differentiator 2 → differentiator 3 → founder → pricing → footer.

## Component Vocabulary

### Persona avatar (locked)

- Two-letter initials of persona name in a 32px circle (24px on mobile).
- Background: `--accent` (Apple blue) at 100% (or a soft ~15% tint of accent for a lighter fill — TBD, see TODO).
- Foreground: white initials, Inter 12px semibold (Inter 11px on 24px circle).
- Letter-spacing: +0.05em for tighter optical balance.
- Position: precedes every agent message. Vertically aligned to first line of message text. On the persona's first message of the session, persona name is displayed inline beside avatar in Inter 14px medium `--text-primary`; subsequent messages omit the name (avatar alone is sufficient).

### Citation pill

- **Inline marker:** small superscript number `¹ ² ³` in `--accent-text` (#0066CC), font-size 70% of body, vertical-align super. Cursor: pointer.
- **Underline cue:** the preceding word/phrase gets a subtle dotted underline (`text-decoration: underline dotted` with `text-underline-offset: 2px` and `text-decoration-color: var(--text-muted)`) so the affordance is visible.
- **Hover popover (desktop):** ~320px wide card. White `--bg-base`, 12px corner radius, 16px padding, subtle shadow (`box-shadow: 0 4px 16px rgba(0,0,0,0.08)`). Layout:
  - **Header row:** source label in Inter 13px semibold `--text-secondary` (e.g. "SP-API · Brand Analytics").
  - **Detail row:** 1-line specifier in Inter 12px regular `--text-muted` (e.g. "Search-term performance, week ending 2026-05-04").
  - **Data preview:** 4-row mini data table or 1-line excerpt in Inter 13px regular `--text-primary`.
  - **Divider:** 1px `--border-subtle`.
  - **Action row:** "Open in Amazon ↗" link in Inter 13px medium `--accent-text`.
- **Mobile (≤767px):** tap-to-expand inline beneath the paragraph instead of popover. Same content, 100% width, slides down with 200ms ease-out.

### Uncertainty marker

- Inter italic 400, `--text-muted` color.
- Wrapped in soft brackets if not natural to the sentence.
- NEVER em dashes.

```
I infer this is competitor pressure rather than seasonality, but I'm 70% on this.
```

### Reaction widget (locked)

- 5-emoji widget below each agent message: 👍 👎 🎯 ❓ 🔁
- Each button: 40px square (32px emoji + 8px padding for 44px touch target on mobile), 8px corner radius.
- Resting state: transparent background.
- Hover state: `--bg-elevated` background, 200ms ease-out transition.
- Active (selected) state: `--accent` at 10% opacity background, persistent.
- Click feedback: 150ms scale 0.95 then back; on selection, micro "pulse" of the emoji glyph.
- **No counters** (single-user reactions, not Slack-style).
- **Mapping (locked):**
  - 👍 = positive gold-standard candidate
  - 👎 = flag for review (expandable text input slides down)
  - 🎯 = exactly right
  - ❓ = unclear
  - 🔁 = wrong, retry

#### 👎 expanded state

On 👎 click, an inline single-line text input slides down beneath the reaction row, full-width of the message body. Background `--bg-elevated`, 8px corner radius, 12px padding. Placeholder: "Tell me what was wrong" (`--text-muted`). Submit on Enter. On submit: input collapses, brief "Thanks — logged" confirmation in `--text-muted` Inter 13px italic, fades after 2 seconds.

### Streaming sub-state indicator

- During agent thinking (between user submission and first token):
  - 1px blinking caret in `--accent` (1.2Hz) preceded by sub-state label in Inter 13px regular `--text-muted`.
  - Sub-states cycle: "Planning…" → "Fetching SP-API…" → "Reasoning…"
  - Each sub-state shown for ≥800ms minimum (no flashing).
  - Then streaming begins token-by-token (Vercel AI SDK `useChat` default).
- Aria-live polite on the message container so screen readers announce sub-state transitions.

### Streaming abort

- Vercel AI SDK `useChat` exposes `stop()`. Render an ⌘. button (Cmd+. universal-cancel) at the input field while a stream is in flight. Abort message: persona avatar + Inter italic `--text-muted` "(stopped — ask again or refine)" — TODO for final copy.

## Voice Tone-of-Voice Rules

The persona's written voice. Authored in detail by founder during Phase 1.1 sprint. Universal rules (carry-forward from rev 1, all still apply):

- **Honest by default.** Tells the CEO when revenue is dipping, when their decision was wrong, when their gut is off.
- **Quantifies uncertainty.** "I'm 70% on this." Not "It might be that…" or "Some data suggests…"
- **Distinguishes "I can see" from "I infer".** Cited facts vs. judgments. Visually different (see typography rules above).
- **Apologizes when wrong.** Self-correcting weekly retro ("Last week I told you X — here's how that played out.").
- **Opinionated.** Says "I think we should…" not "the data could suggest…"
- **No corporate softening.** Forbidden phrases: *leverage, synergy, drive engagement, optimize, unlock value, journey, robust, comprehensive, seamless, holistic, nuanced, multifaceted, vibrant, foster, showcase, intricate, fundamental, significant.* If the founder wouldn't say it to a peer in person, the agent doesn't write it.
- **Short sentences over long ones.** Average 12-18 words.
- **Prose, not bullets.** The CEO is paying for written thinking, not a structured response. Use bullets only when the answer is genuinely a list.

### Forbidden voice patterns

- Sycophantic openers: *"Certainly!", "Absolutely!", "Great question!"*
- Hedging closers: *"Let me know if you'd like more details!", "Hope this helps!"*
- Generic AI-speak: *"Based on the data…", "It appears that…", "This suggests…"*
- Em dashes (Garry's law)
- "AI-powered", "Welcome to Copio", "Unlock the power of…"

## Layout Principles

### Information hierarchy

For every screen, before designing pixels, answer:
1. What does the user see first?
2. What do they see second?
3. What do they see third?
4. What can be cut?

If everything competes, nothing wins. If you can only show 3 things, which 3 matter most?

### Subtraction default

Every UI element earns its pixels. Default position: cut it. (Rams, "as little design as possible.")

### Cardless by default (chat)

Cards are forbidden in chat unless the card *is* the interaction. The chat message is not a card. The sidebar thread row is not a card. Use spacing + typography to create grouping; reserve cards for genuinely interactive surfaces (e.g., a draftable PO in Phase 1.6 HITL).

### Bento by default (landing)

The landing page is a bento, not a vertical scroll of full-width sections. Each cell is its own moment. Asymmetric sizes. Cells that are NOT the interaction (e.g. founder line) get a subtle `--bg-bento-tint` background to create visual rhythm without adding decoration.

## Anti-Patterns (Forbidden)

These are AI-slop signals Copio explicitly rejects. Any implementation that introduces these is a bug, not a feature.

1. **Purple/violet/indigo gradient backgrounds** or blue-to-purple color schemes.
2. **3-column symmetrical feature grid** (icon-in-colored-circle + bold title + 2-line description × 3). The bento is the explicit rejection of this pattern.
3. **Icons in colored circles** as section decoration.
4. **Centered everything** (`text-align: center` as default for headings, descriptions, cards).
5. **Uniform large border-radius** on every element (bubbly aesthetic). 16-20px is the bento ceiling.
6. **Decorative blobs**, floating circles, wavy SVG dividers.
7. **Emoji as design elements** (only as functional reaction buttons in chat).
8. **Colored left-border on cards** (warning rail at 30% opacity for degraded answers is OK; static "tip card" decorative left border is not).
9. **Generic hero copy** ("Welcome to X", "Unlock the power of…", "Your all-in-one solution for…", "AI-powered").
10. **Cookie-cutter SaaS section rhythm** (hero → 3 features → testimonials → pricing → CTA). The bento replaces this.
11. **system-ui or -apple-system** as the primary display/body font.
12. **Warm ochre / orange / amber as brand accent** (rev 1 used this — rev 2 explicitly forbids).
13. **Serif italic for uncertainty markers** (rev 1 used Tiempos italic — rev 2 uses Inter italic + cool muted gray).
14. **Dark mode as the primary surface** (rev 1 had dark primary — rev 2 is light primary, dark is a toggle).
15. **Generic placeholder content in marketing samples** ("SKU-A", "Product X", "$XYZ"). Sample brief cells must use real Nutragroup ASINs and real numbers.
16. **Template-voice copy in bento cells** ("Powerful AI insights", "Built for scale", "Trusted by leaders"). Every cell must be voice-driven.

## Accessibility (non-negotiable)

- **Color contrast:** 4.5:1 minimum on body text, 3:1 on display text (WCAG AA).
- **Accent contrast:** `--accent` (#007AFF) on white = 4.16:1 (just under AA). Therefore `--accent` is used ONLY for backgrounds + decorative chrome (CTA bg, persona avatar fill, focus rings). Inline link text + citation pill text use `--accent-text` (#0066CC, 5.4:1 — passes AA).
- **Keyboard nav:** tab through nav → bento cells → footer (landing); through sidebar capabilities → threads → main column → reactions → input (chat). Logical order. Visible focus rings (2px `--accent` outline, 4px offset).
- **Screen reader:** announce "Agent message from [persona name]:" before message body. Capability rows announce "Brand Analytics: syncing, 6 hours remaining" etc.
- **Streaming announcements:** `aria-live="polite"` on the message container; `aria-busy="true"` while sub-state cycles.
- **Reduce-motion:** respect `prefers-reduced-motion`. Replace blinking caret with static text. Disable cell-hover lift transitions. Disable streaming token-by-token animation (just append the full message instantly when complete).
- **Skip-to-content link** on landing.
- **Reaction button labels:** each emoji button has `aria-label` describing its semantic meaning ("Mark as exactly right", "Flag for review and explain what was wrong", etc.).
- **Citation popovers:** keyboard-accessible. Tab to citation → Enter to open popover → Esc to close. Popover gets `role="dialog"` + `aria-modal="false"`.
- **Capability row reconnect:** keyboard-accessible button with descriptive label.
- **Dark mode toggle:** announces "Appearance set to dark" / "light" / "system" on change.
